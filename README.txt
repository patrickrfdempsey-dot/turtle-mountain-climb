TURTLE MOUNTAIN CLIMB — CLASSROOM EDITION V2

Update your existing GitHub repository by uploading all five files from this folder:
  server.js
  app.js
  index.html
  style.css
  package.json
Do not upload the ZIP itself. Render will deploy automatically.

BACKUP FIRST: GitHub retains older commits. You can also download a ZIP backup
of the current repository before uploading this upgrade.

Races: 15, 20, 25, 30 actual seconds, with mathematical time equal to real time.
Betting: students start with 5 coins, wager 1–3 or their balance if lower.
Payout: correct +wager; incorrect -wager. Empty balance may still observe.
Workshop: after the four races, spend coins to build a new equation.
Base turtle y=3x (free). +1 slope or +1 b costs 1 coin.
Championship: x=25 seconds, plateau 75–105 feet. Safe turtle that enters
plateau earliest wins; overshooting top or ending below bottom loses.
All students participate; heats of up to five student-built turtles.

Teacher presses START RACE, NEXT, and starts championship heats.
Builds cannot be edited after submitted. Teacher can reset the game.
Rooms are kept in server memory and can reset when Render restarts.

IMPORTANT: Test with teacher + two student tabs before using in a class.
The client and server JavaScript have been syntax-checked, but this package
has not yet been tested on a live Render deployment.
