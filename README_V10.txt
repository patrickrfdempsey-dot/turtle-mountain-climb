TURTLE MOUNTAIN CLIMB — VERSION 10

Teacher and student link: https://bite-hoard.onrender.com/

WHAT'S NEW
- Two different Turtle Training questions are generated each game (table to graph, graph to table); negative coordinates included.
- Each new game chooses a Queen island target of 70, 80, 90, 100, or 110 feet, with the island drawn at that height inside the 60–120 foot lake.
- Maximum bet is half your coins (rounded down), or 1 coin if you have exactly 1. The old three-coin cap is removed.
- A student with zero coins receives one free coin at the beginning of the next betting round.
- Each betting round has a two-minute timer that automatically starts the race. Teachers may pause/resume the timer or start the race early.
- Queen crown tiebreak: among closest safe landings, first equation submitted earns the crown. Equal landing distances still earn equal Queen placement bonuses.
- Existing random betting races, turtle animation, mountain scenery, coin carryover, Queen and King remain.

UPLOAD TO GITHUB
1. Extract this ZIP file.
2. Open https://github.com/patrickrfdempsey-dot/turtle-mountain-climb
3. Choose Add file > Upload files.
4. Upload these FIVE game files from the ZIP root: server.js, app.js, style.css, index.html, package.json.
5. Commit changes. Render should automatically deploy to the already approved URL above.
6. When Render shows Live, hard-refresh the classroom website (Ctrl+Shift+R), and check that the welcome screen shows VERSION 10.

TESTING
Syntax checked with node --check for server.js and app.js; simulated server gameplay with 30 students through all betting rounds, Queen and King, and reset; client UI smoke tests. Not yet verified in a live browser or classroom.

Do not upload this ZIP itself to GitHub, and do not delete/rename your existing Render service.
