TURTLE MOUNTAIN CLIMB — VERSION 8

UPDATES
- Every teacher-created game gets three new sets of balanced race equations with different winners. Teacher reset also generates a fresh set. The 10 / 12 / 15 second races, zoom, bounce, and other animations are unchanged.
- Higher alpine mountains and a rocky basin behind the Queen of the Island lake. Lake math stays 60–120 ft, with 90 ft as the center.
- Large "bite-hoard.onrender.com" link on the home screen and on the teacher's projected Turtle Training screen. The banner does not cover the student coordinate graph on their individual screens.
- All Version 7 functionality is retained: two Turtle Training questions, shared Queen allowance, and King sunrise finale.

UPLOAD TO GITHUB (NOT RENDER)
1. Unzip this archive.
2. Go to https://github.com/patrickrfdempsey-dot/turtle-mountain-climb
3. Click Add file > Upload files.
4. Upload all five game files from the extracted archive: server.js, app.js, style.css, index.html, package.json.
5. Click Commit changes. These filenames replace older versions on GitHub.
6. Let the existing Render service deploy. Keep the existing approved URL https://bite-hoard.onrender.com/
7. Refresh the game in Chrome (Ctrl + Shift + R). Home screen should read VERSION 8 and show the big URL.

TESTS
- 500 randomly generated classroom games checked for unique winning turtles, different winners between consecutive rounds, integer equations, nonnegative y-intercepts, and close finishes.
- JavaScript syntax verified. Actual live browser / Render deployment not tested.
